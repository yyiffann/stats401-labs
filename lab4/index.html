Lab 4: Cleaning Web Data for Visualization

This visualization explores the relationship between tweet sentiment and retweet count.

Analysis

This dataset contains 1,000 randomly sampled tweets about ChatGPT collected from a larger dataset of tweets posted in March 2023. The data were checked for missing values, duplicate records, duplicate IDs, negative engagement values, invalid dates, and empty tweet text. Sentiment was calculated using the RoBERTa-based Twitter sentiment model, producing a sentiment label and a sentiment score for each tweet. For visualization, tweets were divided into three retweet groups: No Retweets, Low (1–10 retweets), and High (more than 10 retweets). The x-axis represents retweet group, the y-axis represents the number of tweets, and color represents sentiment. Most tweets received no retweets, and neutral sentiment was the most common category. Because the high-retweet group contains relatively few tweets, differences in sentiment should be interpreted cautiously.
