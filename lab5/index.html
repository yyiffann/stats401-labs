Lab 5: Interactive Network Visualization

1. Dataset Description

This visualization shows a synthetic urban transit network containing 50 stations and 50 direct transit connections. Stations belong to five districts: Central, North, South, East, and West.

Station size represents daily passenger volume, station color represents district, and station shape represents station type. Route width represents travel time, while route color represents route type.

2. Node-Link Visualization

3. Node-Link Design Description

District is encoded by node color so that stations in the same geographic district can be identified quickly. Daily passenger volume is encoded by node size, making high-volume stations more visually prominent. Station type is represented by node shape, allowing local, transfer, and terminal stations to be distinguished. Travel time is encoded by link width, while route type is encoded by link color. Dragging allows users to rearrange the network, while hovering highlights connected stations and provides detailed station information through tooltips.

4. Adjacency Matrix

5. Matrix Design Description

Rows and columns represent the same 50 stations. A colored cell indicates a direct connection between two stations. Cell color represents route type, while cell opacity represents travel time. Stations are ordered by district so that groups of stations from the same district appear together and larger connection patterns can be inspected more easily.

6. Network Questions and Findings

1. Which stations appear central in the network?

The node-link view is most useful for this question because highly connected stations are visually prominent. Stations with several direct connections, such as Station 4, Station 7, Station 10, Station 13, and Station 16, appear relatively central in the network.

2. Which districts are strongly connected to one another?

The adjacency matrix is useful because connections between groups of stations can be compared systematically. The East-South, Central-North, and East-West district pairs show particularly strong connection patterns in the network.

3. Where are transfer or terminal stations located in the topology?

The node-link view is most useful because station shape directly identifies transfer and terminal stations. These stations can also be inspected together with their surrounding connections using hover highlighting.

4. Which stations have high passenger volume?

The node-link visualization answers this most easily because passenger volume is encoded by node size. Stations toward the higher end of the passenger-volume range, especially Station 48, Station 49, and Station 50, appear as larger nodes.

5. Where are the longest direct travel-time connections?

The node-link view is most useful because travel time is encoded by link width. The strongest examples include the connections between Station 7 and Station 31, Station 18 and Station 34, and Station 29 and Station 50.

6. Are particular route types concentrated in particular parts of the network?

Both views can help answer this question. The node-link view makes the route-type colors easy to follow along the network, while the adjacency matrix makes repeated patterns easier to compare. The route types are distributed throughout the network rather than being limited to one clearly separated region.
