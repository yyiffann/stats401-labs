Lab 6 — GDP Hierarchy

Treemap 1: Squarify

Treemap 2: Binary

Design Description

GDP amount is represented by rectangle area, so countries with larger GDP occupy more space. GDP status is represented using color, allowing users to distinguish increases, unchanged values, and decreases. The first treemap uses squarify, which tends to create more square-like rectangles and can make individual countries easier to compare. The second treemap uses binary subdivision, which creates a different spatial organization while preserving the same hierarchical structure and quantitative values. Comparing the two layouts shows how segmentation strategy changes the spatial arrangement of the same hierarchical data.
